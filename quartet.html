Native Android apps, not just websites.

Quartet QE drives native Android apps as well as websites and phone browsers, from the same plain-English story. One story can also check the APIs, queues and databases behind the screen.

One run, four stops.

The AI does the thinking once. After that, the recording does the work.

Story

Type it, point at a file, or pull a ticket from Jira, Azure DevOps, GitHub or GitLab.

Tests

The AI reads your contracts, telemetry and principles, reuses your steps, then writes and validates the tests.

Replay

The recording is the test. Reruns, in CI or on a laptop, use no AI.

Every run after

Go

An independent review and a traceability matrix on one page. A person approves.

Reports you can hand over.

Every run writes a branded, self-contained report. Open it in a browser, attach it to a ticket, or publish it from Jenkins.

ResultsEach test against the story it came from, in a traceability matrix.
ScreenshotsA picture of every step, for each target.
ReviewAn independent check that reads the tests before they run.
JenkinsThe report publishes into your build page.

It runs on your machine.

Within limits you can read and check.

AccountNone. No server of ours and no usage tracking.
ToolsEach tool is labelled read-only, destructive or open-world, so the app can ask before anything risky.
FilesAccess is confined, symlinks are checked and credential files are refused.
SecretsTokens go in the plugin or extension settings, never through the chat.
ReleasesSHA-256 checksums, a software bill of materials and GitHub build provenance.

Install Quartet QE.

In Claude Code, add the marketplace, then install. The settings dialog asks for your tracker and Jenkins details.

/plugin marketplace add Callahan-ci/quartet-qe
/plugin install quartet-qe@quartet-qe
