0.2.2 26 November 2026 Latest release

0.2.2 — a found bug stays found.

A test that catches a real bug now fails the same way on every replay until the bug is fixed, then passes on its own.

  • added
    When a test fails, usually because it found a real bug, its steps are kept in recordings/_unproven/ with why it failed, instead of being dropped.
  • added
    Every replay, in CI too, runs those steps with no AI and shows the real failure, rather than "No recording".
  • added
    Once the bug is fixed, the next replay passes and the steps become an ordinary recording, with no AI and no re-recording. Unproven steps can never make a test pass on their own.
  • fixed
    A replay that stops on unproven steps names the failed run they came from and what failed.

0.2.1 26 November 2026 First-run fixes

0.2.1 — a smoother first run.

Fixes from a fresh install by someone who had never seen Quartet QE.

  • fixed
    Installing from a second copy no longer switches every tests repo on the machine without asking. The installer asks, or keeps the copy in use and says how to switch with --switch.
  • fixed
    A new site is no longer added silently to a tests repo chosen earlier that already has tests: Quartet asks whether to start a new tests repo. Every start now names the repo it is working in.
  • fixed
    The review page lists findings that do not block merging under "Needs your attention" as "Worth a look", instead of hiding them in a collapsed table.
  • fixed
    On the chat path the review says your chat tool counts the tokens, instead of showing 0 tokens.
  • fixed
    Demos end with the review page link, and the README and guide wording is corrected.

0.2.0 25 November 2026 Transaction tracing

0.2 — follow one transaction through every system.

One test can now prove a transaction went through the API, the database and Kafka, and that the services linked it themselves.

  • added
    Follow one transaction through every system. Every API request, page request to the app under test and Kafka event Quartet sends carries a W3C traceparent with the test's trace id. Quartet adds it, not the AI, so recordings do not change and replays carry it too.
  • added
    Kafka events Quartet finds report the trace they carried. A test can prove a service passed the transaction on: assertThat(agent.trace().reached("order-events")).isTrue().
  • added
    The run report draws each transaction: the value threaded with with(...), the systems in order, and each hop as trace sent, same trace, linked by value or no trace, with the trace id to search for in Jaeger, Tempo or Grafana.
  • added
    The demo shop passes the trace on like an OpenTelemetry service, and --prove plants a drop-trace bug that the checkout test catches.
  • changed
    Listed in the official MCP registry as io.github.Callahan-ci/quartet-qe and on Glama; the README opens with a looping overview.

0.1.0 23 November 2026 First release

0.1 — the first public release.

Early release, working and installable. Expect rapid changes; please open an issue if you find one.

  • added
    Writes end-to-end tests from a user story, read from a file, Jira, Azure DevOps, GitHub or GitLab. Vague stories get questions back, not tests.
  • added
    Record once, replay with no AI: the first run records each verified step to recordings/, and every rerun replays them by default (QUARTET_MODE=replay). A step that stops working is handed back to the AI and re-recorded, never guessed.
  • added
    One test can cover web (Chromium, Firefox and WebKit through Playwright), phone browsers, REST APIs guided by OpenAPI and Pact, Kafka with JSON Schema, PostgreSQL and MongoDB.
  • added
    Native Android apps through adb and the accessibility tree, with nothing installed on the device and no Appium. Native iOS through a small XCTest runner, newer and not yet proven on a real run.
  • added
    An independent review and a review page with screenshots of every screen a test reached. A person approves; the AI never merges.
  • added
    Runs as an MCP server, so the AI in your chat tool can write the tests with no API key. Also works with Anthropic, OpenAI, Azure OpenAI, Gemini or any OpenAI-compatible model.
  • added
    Claude Code plugin: /plugin marketplace add Callahan-ci/quartet-qe then /plugin install quartet-qe@quartet-qe.
  • added
    setup-jenkins writes the Jenkinsfile and creates a multibranch job; each build replays with no AI.
  • security
    Release bundles for macOS and Linux (Intel and ARM), a software bill of materials and SHA256SUMS.
