Six stages, one binary.

A pipeline is a straight line of deterministic stages. Each runs natively on the host, no containers required, and emits events the agents subscribe to.

Ingest

GitHub push and PR, GitLab push and MR webhooks.

Plan

Callahanfile.yaml, in GitHub Actions syntax.

Build

A shell process per step, logs streamed live.

AI

Diff review and failure triage.

Scan

Trivy and Semgrep, with an AI fallback.

Post

Review and scan summary on the originating PR.

Built in, no plugins.

Pipelines, AI review, security scanning, PR comments and a dashboard, all in the binary.

YAML or EnglishGitHub Actions-compatible YAML. Prefer to describe it in plain English? The Architect writes the YAML and commits it.
Host-nativeEach step runs as a shell process under your user. State is one SQLite file. Logs stream to the dashboard over a WebSocket.
Your modelClaude, GPT-4o, Groq (Llama 3.3) or Ollama. Switch in settings, no rebuild. No key? It falls back to Ollama.
SecurityIf Trivy or Semgrep are on the runner, every build runs them and shows the findings. If neither is installed, the AI reviews the source instead.
DeployThe deploy step is a shell: kubectl, fly, vercel, terraform, whatever you already use.
WebhooksHMAC-verified webhooks in from GitHub and GitLab; results back to the PR as one markdown comment.
Live logsStreaming output and a one-click plain-English diagnosis on any failed step.

Four agents on every build.

Each is one LLM call with structured input and output, scoped to one task. Turn any of them off in the ai: block of your Callahanfile.

ArchitectPlain English to Callahanfile.yaml, committed back to the repo.

"Build my Next.js app, run Playwright tests, scan with Trivy, deploy to Fly on green main pushes."

DebuggerReads a failed job's logs and the Callahanfile; returns the root cause and the next step.

"npm couldn't find package.json. The repo is Go: replace the build step with go build ./..."

ReviewerA structured review of every build's diff, posted on the pull request.

internal/auth.go:23: password hashed with MD5. Use bcrypt or argon2id.

AnalystTrivy and Semgrep findings, bucketed by severity and explained.

Critical: a GitHub token in internal/auth/auth.go:14. Rotate it and move it to project secrets.

Where it fits.

Not a Jenkins replacement for a 200-engineer organisation. The local-first option for solo developers and small teams who want CI on their own machine, with AI parts that already work.

Two ways in.

macOS, Linux and WSL2. Docker is the quickest if you just want to run it. The docs cover the rest.

Docker Compose

Docker 24 or newer.

Clonegit clone https://github.com/Callahan-ci/Callahan && cd Callahan && cp .env.example .env
KeyANTHROPIC_API_KEY=sk-ant-…
Launchdocker compose up --build
Openopen http://localhost:8080

From source

Go 1.22 or newer and Node 18 or newer.

Clonegit clone https://github.com/Callahan-ci/Callahan
Keyecho 'ANTHROPIC_API_KEY=sk-ant-…' >> .env
Startcd Callahan && ./start.sh dev
Openopen http://localhost:3000

The key is optional: skip it to use Ollama locally.
